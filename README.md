# A.FLOWERS — сайт-витрина цветочной студии

Статический сайт на **Vite + React + TypeScript** с анимациями **GSAP / ScrollTrigger** и плавным скроллом **Lenis**.
Без сервера, базы данных, корзины и онлайн-оплаты: заказы уходят в Telegram, WhatsApp, Instagram и на почту.

Заметки по бренду, цветам и источникам — в [BRAND_NOTES.md](BRAND_NOTES.md).
Источники фото-заглушек — в [public/images/CREDITS.md](public/images/CREDITS.md).

---

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который напишет Vite (обычно http://localhost:5173).

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run build` | проверяет типы и собирает сайт в папку `dist/` |
| `npm run preview` | показывает собранный сайт локально |
| `npm run images` | пересоздаёт оптимизированные фото из `source-images/` (см. ниже) |
| `npm run lint` | проверка кода линтером |

## Как заменить фото, цены и тексты

Весь контент лежит в папке `src/content/`. Вёрстку трогать не нужно.

### Тексты, контакты, ссылки, цены

Файл **`src/content/site.config.ts`**.

- Название, слоган, город — раздел `brand`.
- Контакты и ссылки (Telegram, WhatsApp, Instagram, почта, телефон) — раздел `contacts`.
  Телефон сейчас `'{{PHONE}}'`: пока там плейсхолдер, блок с телефоном на сайте скрыт.
  Чтобы показать телефон, впишите его вместо плейсхолдера: `phone: '+7 999 000-00-00'`.
- Тексты блока «О студии» — раздел `about` (там же `draft: true`: уберите, когда текст станет авторским).
- Уровни цен — раздел `pricing.tiers`: название, цена `priceFrom` (число без пробелов), описание.
- Подпись под ценами — `pricing.note`.
- «Как заказать» — `howToOrder.steps` и `howToOrder.note`.
  Способы оплаты — `paymentMethods: '{{PAYMENT_METHODS}}'`: впишите текст, например `'Перевод по СБП или наличными курьеру'`.
- Доставка — `delivery.info: '{{DELIVERY_INFO}}'`: впишите условия, например `'По Москве в пределах МКАД — 800 ₽, за МКАД — по договорённости'`.
- Отзывы — `reviews.enabled: false`. Когда появятся настоящие отзывы, поставьте `true` и добавьте их в `items`:
  ```ts
  items: [{ author: 'Анна', text: 'Букет был идеальным…', source: 'Instagram' }]
  ```
- Сноска про Instagram и тексты cookie-баннера — раздел `legal`.
- Яндекс Метрика — `analytics.yandexMetrikaId: ''`. Впишите номер счётчика в кавычках, и аналитика включится вместе с cookie-баннером. Цели для Метрики перечислены в `analytics.goals` — создайте в Метрике цели типа «JavaScript-событие» с такими же идентификаторами.
- Адрес сайта — `siteUrl` (нужен для микроразметки и Open Graph). Тот же адрес впишите в `public/sitemap.xml` и `public/robots.txt`.

### Композиции (букеты)

Файл **`src/content/bouquets.ts`** — список композиций. У каждой:

```ts
{
  id: 'bordeaux',                 // латиницей, уникальный, без пробелов
  name: 'Бордо',                  // название
  images: ['bordeaux-1', 'bordeaux-2'], // имена фото (см. ниже); пустой массив [] = заглушка «фото скоро»
  composition: ['бордовые садовые розы', 'ранункулюсы', 'эвкалипт'],
  priceFrom: 20000,               // цена «от», число
  size: 'L',                      // S, M, L или XL
  occasions: ['romance', 'anniversary'], // поводы (список значений — в src/content/finder.ts)
  recipients: ['her'],            // кому: her, him, mom, colleague, home, any
  palette: 'red',                 // гамма: white, pink, red, bright, green
  why: 'Глубокий винный тон — признание, которое не нуждается в словах.',
  season: 'ранункулюсы — ноябрь–апрель', // необязательно
  flowerIds: ['garden-rose', 'ranunculus', 'eucalyptus'], // для фильтра «композиции с этим цветком»
  draft: true,
}
```

Чтобы добавить композицию — скопируйте любой блок и поменяйте значения. Чтобы убрать — удалите блок.

### Виды цветов

Файл **`src/content/flowers.ts`**: название, фото (`image`), описание, сезон, символика. `image: null` — заглушка «фото скоро».

### Фото

1. Положите исходное фото (jpg, jpeg, png или webp, лучше вертикальное, от 1200 px по ширине) в папку:
   - `source-images/bouquets/` — для композиций,
   - `source-images/flowers/` — для видов цветов,
   - `source-images/about/` — для блока «О студии»,
   - `source-images/wide/` — горизонтальный фон блока «Контакты».
2. Имя файла без расширения — это и есть значение в данных. Например, файл `source-images/bouquets/bordeaux-1.jpg` → в `bouquets.ts` пишем `images: ['bordeaux-1']`.
   Заменить существующее фото = положить новый файл с тем же именем.
3. Выполните:
   ```bash
   npm run images
   ```
   Скрипт сам обрежет фото под нужные пропорции (4:5 для карточек), сделает три размера и сохранит в `public/images/` в формате WebP.

Старые исходники с Unsplash можно удалять из `source-images/` по мере замены.

### Логотип

Логотип собран в SVG по фото открытки: `src/components/ui/Logo.tsx`. Если появится оригинальный файл логотипа, замените разметку в этом компоненте (или вставьте `<img>` с вашим файлом). Favicon — `public/favicon.svg`, иконка для iPhone — `public/apple-touch-icon.png`, картинка для соцсетей — `public/og.jpg`.

### Статичный конверт в index.html

В `index.html` есть блок `#pre-hero` — упрощённый конверт на чистом CSS. Он показывается в первые доли секунды, пока грузится JavaScript, и удаляется, как только React отрисует настоящий конверт. Если меняете цвета конверта в `tokens.css` / `Envelope.module.css`, поправьте и цвета в этом блоке.

### Цвета и шрифты

Все цвета, шрифты, отступы и радиусы — в `src/styles/tokens.css`. Шрифты подключены локально (`@fontsource`), с интернета ничего не грузится.

## Структура

```
src/
  content/        ← ВЕСЬ контент: site.config.ts, bouquets.ts, flowers.ts, finder.ts
  components/
    envelope/     ← конверт на первом экране (Envelope.tsx, Seal.tsx)
    background/   ← живой фон: пятна света, лепестки, зерно
    sections/     ← блоки страницы (О студии, Подбор, Галерея, Цветы, Цены, …)
    order/        ← кнопки связи, мобильная кнопка «Заказать»
    layout/       ← шапка, футер, заголовки секций, бегущая строка, cookie-баннер
    ui/           ← логотип, иконки, картинки, тост
  lib/            ← подбор композиции, текст заказа, аналитика, скролл, анимации
  pages/          ← Home.tsx (главная), Privacy.tsx (политика)
  styles/         ← tokens.css (дизайн-токены), global.css
public/images/    ← оптимизированные фото (генерируются скриптом)
source-images/    ← исходные фото
scripts/images.mjs ← скрипт оптимизации фото
```

## Как задеплоить

Сайт статический: подойдёт Vercel, Netlify, GitHub Pages или любой хостинг, который умеет отдавать папку.

**Vercel**
1. Загрузите проект в GitHub (или GitLab).
2. На vercel.com → «Add New Project» → выберите репозиторий. Vercel сам определит Vite: команда сборки `npm run build`, папка `dist`.
3. Нажмите Deploy. Файл `vercel.json` уже настроен (страница `/privacy` открывается напрямую, картинки кэшируются).

**Netlify**
1. На app.netlify.com → «Add new site» → «Import an existing project» → репозиторий.
2. Build command: `npm run build`, Publish directory: `dist`.
3. Файл `public/_redirects` уже настроен для прямого открытия `/privacy`.

После деплоя впишите реальный домен в `siteUrl` (`src/content/site.config.ts`), `public/sitemap.xml` и `public/robots.txt`.

## Что осталось плейсхолдером

- `{{PHONE}}` — телефон (блок скрыт).
- `{{DELIVERY_INFO}}` — условия и стоимость доставки.
- `{{PAYMENT_METHODS}}` — способы оплаты.
- `https://example.com` — адрес сайта.
- Тексты блоков и композиции помечены `draft: true` — демонстрационные.
- Фото — с Unsplash, заменить на собственные.
- Текст политики конфиденциальности — черновик, нужно утвердить.
- Отзывы — выключены до появления настоящих.
